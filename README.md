# Протокол → Excel, версия 2

Локальная программа с окном: несколько протоколов DOCX / PDF → проверка и исправление полей → новая копия вашей таблицы Excel и текстовый отчёт. Документы никуда не отправляются; внешние API и ключи не нужны.

Поддерживается распознавание повёрнутых сканов PDF. **«Партія (позначення)» заполняется датой изготовления**.

## Скачать

Откройте https://github.com/Rostislav999/- и нажмите **Code → Download ZIP**, затем распакуйте архив.

## Запуск в Windows

1. Установите **Python 3.10 или новее** с https://www.python.org/downloads/ (отметьте «Add Python to PATH»).
2. Для сканов установите **Tesseract OCR 5**. Инсталляторы Windows: https://github.com/UB-Mannheim/tesseract/wiki . Стандартная папка — `C:\Program Files\Tesseract-OCR`. Украинская модель и модель поворота уже включены в архив в папке `tessdata`; загружать их отдельно не нужно. Для DOCX и PDF с текстовым слоем Tesseract не требуется.
3. Распакуйте **весь архив**, затем дважды нажмите **start.bat** (или «Запустить_Windows.bat»). При обновлении распакуйте архив в новую папку, чтобы не использовать старую `.venv`. При первом запуске нужен интернет для установки Python-библиотек. Word и Excel для обработки не требуются.
4. Выберите свою исходную таблицу Excel с колонками D–P, перечисленными ниже. Пользовательские протоколы и таблицы в дистрибутив не включены.
5. Нажмите «Добавить DOCX / PDF…» и выберите протоколы. Для сканов отображается ход распознавания; окно остаётся доступным.
6. Выберите каждый документ слева, проверьте поля по оригиналу, исправьте их при необходимости и отметьте «Я проверил(а)…». Пустое поле можно оставить пустым.
7. По умолчанию включено **«Обновлять строки с тем же номером»**: найденные непустые значения записываются в соответствующую строку **новой копии** Excel. Если сведения не найдены в документе, прежние значения Excel сохраняются. Выключите эту опцию, чтобы пропускать существующие номера.
8. Нажмите «Сохранить Excel…» и задайте **новое имя**. Оригиналы не меняются. Рядом появится `.report.txt` с предупреждениями и перечнем сохранённых прежних значений.

При повторном запуске проверяются установленные версии зависимостей; если они подходят, установка и обращение к сети пропускаются. Если Tesseract установлен в нестандартную папку, добавьте её в PATH или задайте переменную `TESSERACT_CMD` с полным путём к `tesseract.exe`. Окно на Windows в облачной среде не проверялось; извлечение и запись Excel проверены на присланном PDF в Linux.

## Если окно запуска закрывается или программа не открывается

Брандмауэр отключать не нужно. Новый запуск показывает этапы подготовки и сохраняет диагностику:

- `logs/launcher.log` — поиск Python;
- `logs/startup.log` — создание среды, установка библиотек и ошибки приложения.

Окно остаётся открытым после завершения. Если старый батник всё ещё закрывается, откройте папку программы, в адресной строке Проводника введите `cmd` и нажмите Enter. Выполните:

```bat
cmd /k start.bat
```

При ошибке отправьте её текст или последние строки соответствующего журнала. Если Python не находится, установите Python 3.12 (64-bit), отметив **Add Python to PATH** и **Tcl/Tk**. Если упомянут `_tkinter`, восстановите установку Python с компонентом Tcl/Tk. Папка должна быть распакована целиком; нужны файлы `bootstrap.py`, `app.py` и `requirements.txt` рядом с `start.bat`.

## Как переносятся сведения

| Excel | Источник |
| --- | --- |
| D — Номер протоколу | Основной заголовок «ПРОТОКОЛ ВИПРОБУВАНЬ №…» |
| E — Дата протоколу | Дата после заголовка, например «28» жовтня 2026 року |
| F — Код каталогу | «Номер за Каталогом продуктів харчування» |
| G — Назва продукту | «Ідентифікаційний номер та назва зразка», включая продолжение на следующей строке |
| H — Партія (позначення) | **Дата изготовления**, как указал пользователь; текст ДД.ММ.ГГГГ |
| I, J — Даты изготовления и «Вжити до» | Соответствующие явно указанные даты |
| K — Партія (кг) | «Розмір партії, від якої відібрано зразок» |
| L — Маса нетто одиниці | Явная масса нетто или вес одной единицы: «9 ж/б по 525 г» → **0,525 кг**, а не общий вес 4,725 кг |
| M, N — Постачальник / Виробник | Коды ЄДРПОУ из 8 цифр, включая продолжения адреса на следующих строках |
| O — Результат випробувань | «Відповідає» / «Не відповідає» из вывода, включая переносы строк |
| P — Відповідність описам Каталогу | Только отдельное явное указание; общий вывод сюда автоматически не копируется |

Даты E/I/J записываются как даты Excel, масса — как числа в килограммах. Если явное обозначение партии отличается от даты изготовления, используется установленное пользователем правило H = I и выводится предупреждение. Если дата изготовления не найдена, программа оставляет явное обозначение партии из документа, если оно есть, для ручной проверки.

Новые номера добавляются после последней заполненной строки; существующие обновляются или пропускаются согласно опции. Служебные столбцы A–C, скрытый лист, выпадающие списки и прочие части шаблона сохраняются. Таблица расширяется при необходимости. Пустые значения, прочерки и подчёркивания не превращаются в выдуманные данные. Введённый текст сохраняется как текст, а не формула. Дубли номеров среди входных файлов и неоднозначное обновление повторяющихся строк Excel блокируются.

## Проверка данных

Извлечение проверено на пользовательских DOCX и повёрнутом скане PDF. Срок «Вжити до» и отдельное соответствие описаниям Каталога заполняются только при наличии явного значения. При обновлении строки значения, не найденные в документе, сохраняются из исходного Excel и перечисляются в отчёте.

OCR может прочитать символ № как цифру 2, буквы Хе или Ме. Номер берётся из основного заголовка; расхождения с распознанными номерами образцов показываются для проверки. Цифры номера не исправляются по догадке. Сверяйте распознанный номер и коды организаций с оригиналом.

## Ограничения

Один документ — одна строка Excel. Парсер рассчитан на структуру присланных украинских протоколов; для существенно другого оформления или нескольких образцов понадобится доработка. Поддерживаются DOCX, текстовые PDF, сканы PDF и смешанные PDF. Старый DOC сохраните как DOCX. Скан распознаётся локально: страницы поворачиваются, развороты с чистым центральным промежутком разбиваются на две части. Низкое качество скана, подписи, печати и нестандартные таблицы могут приводить к ошибкам OCR. Проверяйте данные перед использованием. Файлы PDF с паролем нужно предварительно расшифровать.

Предупреждения относятся к извлечённому исходному тексту и остаются в отчёте после исправления полей в окне. Программа заполняет Excel; импорт во внешнюю учётную систему не проверен.

## Командная строка и разработка

Используйте имеющийся checkout; отдельный Git worktree не нужен.

```sh
cd /workspace/-
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py
```

На Linux нужны системные пакеты Tesseract OCR и tkinter для вашей версии Python; на macOS — Tesseract и Python с Tk. Языковые модели включены в `tessdata`; источники и лицензия указаны там же.

Без графического окна:

```sh
python protocol_excel.py --template "Шаблон.xlsx" --output "Результат.xlsx" --update-existing --accept-review "Протокол.pdf"
```

Без `--update-existing` существующие номера пропускаются. Без `--accept-review` при предупреждениях или пустых полях команда выведет их и завершится без создания Excel. Добавляйте этот параметр после проверки данных.

Проверки: `python -m unittest discover -s tests -v`. Обычные тесты не требуют пользовательских документов, Tesseract или интернета. Работа полного OCR отдельно проверена на присланном скане. Окно требует рабочего стола; в облачной среде без дисплея используйте командную строку.
