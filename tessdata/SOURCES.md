# Модели OCR

Файлы ukr.traineddata и osd.traineddata получены из официального репозитория tesseract-ocr/tessdata_fast по HTTPS:

- https://raw.githubusercontent.com/tesseract-ocr/tessdata_fast/main/ukr.traineddata
- https://raw.githubusercontent.com/tesseract-ocr/tessdata_fast/main/osd.traineddata

Лицензия Apache 2.0 сохранена в файле LICENSE. Контрольные суммы поставляемых файлов записаны в SHA256SUMS для проверки целостности копии. Сам исполняемый Tesseract не включён в архив и устанавливается отдельно.
